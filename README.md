# Proyecto-4
Este proyecto proviene de un concurso en la plataforma Kaggle llamado "Predicción binaria de un conjunto de datos de precipitaciones"
Para este proyecto se utilizó el modelo de predicción KNN (K-Vecinos más cercanos), encontrando que el hiperparámetro óptimo para realizar las predicciones fué n=11.
El modelo tuvo una exactitud de poco más del 85%.
